## 🧑‍💻 About Me

I'm a self-taught programmer based in **New Delhi, India**. My career began in **C**, building Interactive Voice Response System (IVRS) applications for Windows and Linux. Today I focus on **backend development in Rust**, building fast, reliable command-line tools, developer utilities and system-level software that put reliability, efficiency and maintainability ahead of cleverness.

I'm also the founder and Editor-in-Chief of **[Fresh Tech Tips](https://www.freshtechtips.com)**, a technology blog where I write about Linux, Windows, Android, WordPress, developer tools and AI workflows.
